પ્રકરણ - 4 : દ્વિચલ સુરેખ સમીકરણો

દ્વિચલ સુરેખ સમીકરણ શું છે?

જ્યારે કોઈ સમીકરણમાં બે ચલ (બદલાતી રહેતી સંખ્યાઓ), જેમ કે x અને y હોય અને તે બંનેની ઘાત 1 હોય, ત્યારે તેને દ્વિચલ સુરેખ સમીકરણ કહેવાય છે.

ax + by + c = 0

⭐ પ્રમાણિત સ્વરૂપ

દ્વિચલ સુરેખ સમીકરણનું પ્રમાણિત સ્વરૂપ:

ax + by + c = 0

અહીં a, b અને c વાસ્તવિક સંખ્યાઓ છે અને a અને b બંને એકસાથે શૂન્ય ન હોઈ શકે.

સમીકરણને પ્રમાણિત સ્વરૂપમાં કેવી રીતે ફેરવશો?

કોઈપણ સમીકરણને ax + by + c = 0 ના સ્વરૂપમાં લખવા માટે નીચેના પગલાં અનુસરો:

1. સમીકરણની બધી પદોને બરાબરની ડાબી બાજુ લાવો.
2. અચલનું ચિહ્ન યોગ્ય રીતે ગોઠવો.
3. x તથા y વાળા પદ અને અચલ પદને અલગ-અલગ ગોઠવો.

📌 ઉદાહરણ

સમીકરણ:

2x + 3y = 7

7 ને ડાબી બાજુ લાવીએ:

2x + 3y - 7 = 0

અહીં,

a = 2,   b = 3,   c = -7

સમીકરણનો ઉકેલ કેવી રીતે શોધવો?

દ્વિચલ સુરેખ સમીકરણ માટે x અને y ની એવી કિંમતો શોધવાની હોય છે જે સમીકરણને સંતોષે એટલે કે સમીકરણની બંને બાજુઓને સમાન બનાવે.

ધારો કે સમીકરણ છે:

x + y = 5

જો x = 2 મૂકીએ, તો

2 + y = 5

તેથી,

y = 3

અટલે (2,3) સમીકરણનો એક ઉકેલ છે.

સમીકરણના ઉકેલો કેવી રીતે શોધવા?

દ્વિચલ સુરેખ સમીકરણ માટે x અને y ની એવી કિંમતો શોધવાની હોય છે જે સમીકરણનું સમાધાન કરે (એટલે કે ડાબી બાજુની કિંમત જમણી બાજુ મળે).

💡 અનંત ઉકેલ

એક દ્વિચલ સુરેખ સમીકરણને સામાન્ય રીતે અસંખ્ય (અનંત) ઉકેલ હોઈ શકે છે.

જો x ની કિંમત બદલતા જઈએ, તો યોગ્ય y ની કિંમત મેળવી શકાય છે.

આ બધા જ ક્રમબદ્ધ જોડ (x,y) સમીકરણ x + y = 6 ના ઉકેલો છે.

ઉકેલ શોધવાની એક સરળ રીત:

1. x ની કોઈ એક કિંમત ધારો.
દા.ત. x = 0.
2. આ કિંમત સમીકરણમાં મૂકો.
3. y માટે સમીકરણ ઉકેલો.
4. તમને (x, y) સ્વરૂપમાં એક ક્રમબદ્ધ જોડ (ઉકેલ) મળશે.

📌 ઉદાહરણ

સમીકરણ:

2x + y = 8

ધારો કે, x = 0

તો,

2(0) + y = 8

અટલે,

y = 8

તેથી એક ઉકેલ:

(0, 8)

વધુ ઉકેલો શોધીએ

સમીકરણ:

2x + y = 8

જો x = 1:

2(1) + y = 8

y = 6

ઉકેલ = (1,6)

જો x = 2:

2(2) + y = 8

y = 4

ઉકેલ = (2,4)

જો x = 3:

2(3) + y = 8

y = 2

ઉકેલ = (3,2)

જો x = 4:

2(4) + y = 8

y = 0

ઉકેલ = (4,0)

ઉકેલનું કોષ્ટક

⭐ યાદ રાખો

• દ્વિચલ સુરેખ સમીકરણમાં બે ચલ હોય છે.

• સામાન્ય સ્વરૂપ: ax + by + c = 0

• અહીં a, b, c વાસ્તવિક સંખ્યાઓ છે.

• a અને b બંને એકસાથે શૂન્ય ન હોઈ શકે.

• સમીકરણના ઉકેલને સામાન્ય રીતે (x,y) સ્વરૂપમાં લખવામાં આવે છે.

• એક દ્વિચલ સુરેખ સમીકરણને સામાન્ય રીતે અનંત ઉકેલો હોય છે.

ઉદાહરણ 1

નીચે દર્શાવેલ દરેક સમીકરણને ax + by + c = 0 સ્વરૂપે દર્શાવો અને દરેકમાં a, b, c ની કિંમતો દર્શાવો.

(i) 2x + 3y = 4.37

આપેલ સમીકરણ:

2x + 3y = 4.37

બધા પદોને ડાબી બાજુ લાવતાં:

2x + 3y - 4.37 = 0

તેથી,

a = 2     b = 3     c = -4.37

(ii) x - 4 = √3y

આપેલ સમીકરણ:

x - 4 = √3y

બધા પદોને ડાબી બાજુ લાવતાં:

x - √3y - 4 = 0

તેથી,

a = 1     b = -√3     c = -4

(iii) 4 = 5x - 3y

આપેલ સમીકરણ:

4 = 5x - 3y

બધા પદોને ડાબી બાજુ લાવતાં:

5x - 3y - 4 = 0

તેથી,

a = 5     b = -3     c = -4

(iv) 2x = y

આપેલ સમીકરણ:

2x = y

બધા પદોને ડાબી બાજુ લાવતાં:

2x - y = 0

એટલે,

2x - y + 0 = 0

તેથી,

a = 2     b = -1     c = 0

ઉદાહરણ 2

નીચે દર્શાવેલ દરેક સમીકરણને દ્વિચલ સુરેખ સમીકરણ સ્વરૂપે દર્શાવો.

(i) x = -5

આપેલ સમીકરણ:

x = -5

5 ને ડાબી બાજુ લાવતાં:

x + 5 = 0

દ્વિચલ સ્વરૂપમાં:

x + 0y + 5 = 0

(ii) y = -2

આપેલ સમીકરણ:

y = -2

2 ને ડાબી બાજુ લાવતાં:

y + 2 = 0

દ્વિચલ સ્વરૂપમાં:

0x + y + 2 = 0

(iii) 2x = 3

આપેલ સમીકરણ:

2x = 3

3 ને ડાબી બાજુ લાવતાં:

2x - 3 = 0

દ્વિચલ સ્વરૂપમાં:

2x + 0y - 3 = 0

(iv) 5y = 2

આપેલ સમીકરણ:

5y = 2

2 ને ડાબી બાજુ લાવતાં:

5y - 2 = 0

દ્વિચલ સ્વરૂપમાં:

0x + 5y - 2 = 0

⭐ પરીક્ષા માટે યાદ રાખો

દ્વિચલ સુરેખ સમીકરણનું સામાન્ય સ્વરૂપ:

ax + by + c = 0

અહીં a, b, c વાસ્તવિક સંખ્યાઓ છે અને a તથા b બંને એકસાથે શૂન્ય ન હોવા જોઈએ.

• x = -5 → x + 5 = 0

• y = -2 → y + 2 = 0

• 2x = 3 → 2x - 3 = 0

• 5y = 2 → 5y - 2 = 0

∴ x = 4

3) નીચેનામાંથી કયા બિંદુઓ સમીકરણ x - 2y = 4 નો ઉકેલ છે અને ક્યાં બિંદુઓ ઉકેલ નથી તે ચકાસો :

(i) ( 0 , 2 )

જવાબ

x = 0 , y = 2

∴ x - 2y = 4

∴ 0 - 2(2) = 4

∴ - 4 ≠ 4

તેથી , આપેલ બિંદુ સમીકરણનો ઉકેલ નથી.

(ii) ( 2 , 0 )

જવાબ

x = 2 , y = 0

∴ x - 2y = 4

∴ 2 - 2(0) = 4

∴ 2 ≠ 4

તેથી , આપેલ બિંદુ સમીકલણનો ઉકૈલ નથી.

(iii) ( 4 , 0 )

જવાબ

∴ x = 4 , y = 0

∴ x - 2y = 4

∴ 4 - 2(0) = 4

∴ 4 = 4

તેથી , આપેલ બિંદુ સમીકરણનો ઉકેલ છે.

(iv) (√2 , 4 √2)

જવાબ

x = √2 , y = 4√2

∴ x - 2y = 4

∴ √2 - 2 ( 4 √2 ) = 4

∴ √2 - 8 √2 = 4

∴ √2 ( 1 - 8 ) = 4

∴ √2 ( - 7 ) = 4

∴ - 7 √2 ≠ 4

તેથી , આપેલ બિંદુ સમીકરણનો ઉકેલ નથી.

(v) ( 1 , 1 )

જવાબ

x = 1 , y = 1

∴ x - 2y = 4

∴ 1 - 2(1) = 4

∴ 1 - 2 = 4

∴ - 1 ≠ 4

તેથી , આપેલ બિંદુ સમીકરણના ઉકેલ નથી.
