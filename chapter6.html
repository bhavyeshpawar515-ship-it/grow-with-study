પ્રકરણ - 6 : રેખાઓ અને ખૂણાઓ

Basic concepts

1.રેખાખંડ

" બે અંત્યબિંદુઓવાળા રેખાના ભાગને ' રેખાખંડ' કહે છે."

2.કિરણ

" એક જ અંત્યબિંદુ ધરાવતા રેખાના ભાગને કિરણ કહે છે."

3. સમરેખ બિંદુઓ

" જો ત્રણ કે ત્રણથી વધારે બિંદુઓ એક જ રેખા પર આવેલા હોય , તો તે બિંદુઓને સમરેખ બિંદુઓ કહે છે."

4. અસમરેખ બિંદુઓ

" જો ત્રણ કે ત્રણથી વધારે બિંદુઓ એક જ રેખા પર ન આવેલા હોય , તો તે બિંદુઓને અસમરેખ બિંદુઓ કહે છે."

5. ખૂણો

" જ્યારે બે કિરણો એક સામાન્ય અંત્યબિંદુમાંથી ઉદભવે ત્યારે ખૂણો બને છે. "

• ખૂણો બનાવતા કિરણોને ખૂણાની બાજુઓ કહેવામાં આવે છે અને સામાન્ય અંત્યબિંદુને ખૂણાનું શિરોબિંદુ કહે છે.

• આક્રુતિમાં કિરણ BA અને કિરણ BC એ ખૂણો ABC ની બાજુઓ છે, તથા બિંદુ B ખૂણો ABC નું શિરોબિંદુ છે.

ખૂણાઓના પ્રકાર

1) લઘુકોણ ખૂણો

" જે ખૂણાનું માપ 90° થી ઓછું હોય, તે ખૂણાને લઘુકોણ ખૂણો કહે છે."

• આક્રુતિમાં ખૂણો ABC એ લઘુકોણ ખૂણો છે.

• ( 0° < x < 90° )

• 0° થી 90° ની વચ્ચેના ખૂણા લઘુકોણના ખૂણા

2) કાટકોણ ખૂણો

" જે ખૂણાનું માપ 90° હોય, તે ખૂણાને કાટકોણ ખૂણો કહે છે."

• કાટકોણ ખૂણાને કાટખૂણો પણ કહે છે.

• આક્રુતિમાં ખૂણો PQR કાટકોણ ખૂણો છે.

∴ ખૂણો PQR = 90°

3) ગુરુકોણ ખૂણો

" જે ખૂણાનું માપ 90° અને 180° ની વચ્ચે હોય, તે ખૂણાને ગુરુકોણ ખૂણો કહે છે."

• આક્રુતિમાં ખૂણો MOP ગુરુકોણ ખૂણો છે.

• ( 90° < a < 180° )

4) સરળકોણ ખૂણો

" જે ખૂણાનું માપ 180° હોય, તે ખૂણાને કોણ સરળખૂણો કહે છે."

• આક્રુતિમાં ખૂણો XYZ એ સરળકોણ ખૂણો છે.

∴ ખૂણો XYZ = 180°

5) વિપરીતકોણ

" જે ખૂણાનું માપ 180° અને 360° ની વચ્ચે હોય, તે ખૂણાને વિપરીતકોણ ખૂણો કહે છે."

• આક્રુતિમાં ખૂણો DEV એ વિપરીતકોણ ખૂણો છે.

• ( 180° < y < 360° )

• ખૂણો DEV ને વિપરીત ખૂણો DEV વંચાય છે અને લખાય છે.

ખૂણાઓની જોડના પ્રકાર

1) કોટિકોણ

" જે બે ખૂણાઓના માપનો સરવાળો 90° થાય તે ખૂણાઓને એકબીજાના કોટિકોણ કહે છે. "

•

2) પૂરકકોણ

" જે બે ખૂણાઓના માપનો સરવાળો 180° થાય તે ખૂણાઓને એકબીજાના પૂરકકોણ કહે છે. "

• એટલે કે જો ખૂણો P + ખૂણો Q = 180° તો P અને Q એકબીજાના પૂરકકોણ છે.

3) આસન્નકોણ

" જો બે ખૂણાઓનું શિરોબિંદુ એક જ હોય , એક ભુજ સામાન્ય હોય અને સામાન્ય ન હોય તેવા ભુજ એ સામાન્ય ભુજની જુદી-જુદી બાજુએ હોય તેવા બે ખૂણાઓને આસન્નકોણ કહે છે."

• આક્રુતિમાં ખૂણો ABD અને ખૂણો DBC એ આસન્નકોણ છે.

• પરિણામ : ખૂણો ABC = ABD + DBC

4) રૈખિક જોડના ખૂણા

" આસન્ન કોણની જોડના બે ખૂણાઓના સામાન્ય ન હોય તેવા ભુજ એક રેખા બનાવે તો તે આસન્ન કોણની જોડના બંને ખૂણાઓને રૈખિક જોડના ખૂણા કહે છે."

• આક્રુતિમાં ખૂણો AOC અને ખૂણો BOC એ રૈખિક જોડના ખૂણા છે.

5) અભિકોણો

" પરસ્પર છેદતી બે ભિન્ન રેખાઓના કેન્દ્ર આગળ બનતા ખૂણાઓમાં જે બે ખૂણાઓની બાજુઓ એકબીજા માટે વિરુદ્ધ કિરણો હોય તેવા ખૂણાઓને અભિકોણની જોડના ખૂણા કહે છે."

• આક્રુતિમાં રેખા AB અને રેખા CD પરસ્પર O બિંદુઓ છેદે છે.

• ખૂણાઓ AOD અને BOC અભિકોણની જોડના ખૂણાઓ છે, તથા AOC અને BOD પણ અભિકોણની જોડના ખૂણાઓ છે.

પૂર્વધારણા 6.1

જે કિરણનું ઉદભવબિંદુ રેખા પર હોય તેવા કિરણ અને રેખાથી બનતા બંને ખૂણાઓનો સરવાળો 180° થાય છે.

• પૂર્વધારણા મુજબ AOC + BOC = 180°

• રૈખિક જોડના ખૂણાઓનો સરવાળો 180° થાય છે.

પૂર્વધારણા 6.2

જે બે આસન્નકોણોનો સરવાળો 180° હોય , તો તેની સામાન્ય ન હોય તેવી બાજુઓ એક રેખા બનાવે છે.

• જો AOC + BOC = 180 ° તો AB એ રેખા છે.

પ્રમેય 6.1 : અભિકોણનું પ્રમેય

વિધાન : પરસ્પર છેદતી બે રેખાથી બનતા અભિકોણ સમાન હોય છે.

પક્ષ : રેખા AB અને રેખા CD પરસ્પર O બિંદુમાં છે. AOD અને BOC તથા AOC અને BOD અભિકોણની જોડના ખૂણા છે.

સાધ્ય : (1) AOD = BOC

(2) AOC = BOD

સાબિતિ : AOD અને BOD રૈખિક જોડના ખૂણા છે.

∴ AOD + BOD = 180° __________ (1)

હવે , BOD અને BOC રૈખિક જોડના ખૂણા છે.

∴ BOD + BOC = 180° __________ (2)

સમીકરણ (1) અને(2) પરથી ,

∴ AOD + BOD = BOD + BOC

∴ AOD = BOC

• તે જ રીતે AOC = BOD પણ સાબિત કરી શકાય છે.

ઉદાહરણ - 1) આક્રુતિમાં રેખા PQ અને રેખા RS એકબીજીને બિંદુ O માં છેદે છે. જો POR : ROQ = 5 : 7 હોય , તો તમામ ખૂણાઓ શોધો.

જવાબ : અહીં , POR : ROQ = 5 : 7

ધારો કે , POR = 5x

ROQ = 7x

હવે , POR + ROQ = 180° ( ∴ રૈખિક જોડ )

∴ 5x + 7x = 180°

∴ 12x = 180°

∴ x = 180°/12

∴ x = 15°

POR = 5x = 5 × 25 = 75°

ROQ = 7x = 7 × 15 = 105°

• હવે , POR = SOQ ( ∴ અભિકોણ )

∴ SOQ = 75°

• અને ROQ = SOP ( ∴ અભિકોણ )

∴ SOP = 105°

ઉદાહરણ - 2) આક્રુતિમાં કિરણ OS રેખા POQ પર છે. કિરણ OR અને કિરણ OT એ અનુક્રમે POS અને SOQ ના કોણદ્વિભાજક છે. જો POS = x , તો ROT શોધો.

જવાબ અહીં , POS = x છે અને કિરણ OR એ POS નો કોણદ્વિભાજક છે.

∴ ROS = 1/2 POS

∴ ROS = 1/2 x

∴ ROS = x/2

POS + SOQ = 180° ( રૈખિક જોડ )

∴ x + SOQ = 180°

∴ SOQ = 180° - x

• હવે , કિરણ OT એ SOQ નો કોણદ્વિભાજક છે.

∴ SOT = 1/2 SOQ

∴ SOT = 1/2 ( 180° - x )

∴ SOT = 180°/2 - x/2

∴ SOT = 90° - x/2

• હવે , ROT = ROS + SOT

∴ ROT = x/2 + 90° - x/2

∴ ROT = 90°

ઉદાહરણ - 3 ) આક્રુતિમાં OP , OQ , OR અને OS ચાર કિરણ છે. તો સાબિત કરો કે , POQ + QOR + SOR + POS = 360°

જવાબ : • કિરણ OQ ને વિરુદ્ધ દિશામાં લંબાવી કિરણ OT દોરો.

• POT + POQ = 180° __________ (1)( ∴ રૈખિક જોડ )

∴ TOS + SOQ = 180° ( ∴ રૈખિક જોડ )

∴ TOS + SOR + QOR = 180° __________ (2)

• સમીકરણ (1) અને (2) નો સરવાળો કરતાં ,

∴ POT + POQ + TOS + SOR + QOR = 180° + 180°

∴ (POT + TOS) + POQ + SOR + QOR = 180° + 180°

∴ POS + POQ + SOR + QOR = 360°

સ્વાધ્યાય 6.1

પ્રશ્ર - 1) આક્રુતિમાં રેખા AB અને રેખા CD , O માં છેદે છે. જો AOC + BOE = 70° અને BOD = 40° , તો BOE અને વિપરીત COE મેળવો.

જવાબ - • અહીં AOC + BOE = 70°

અને BOD = 40°

• હવે , AOC = BOD (∴ અભિકોણ )

∴ AOC = 40°

• અહીં , AOC + BOE = 70°

∴ 40° + BOE = 70°

∴ BOE = 70° - 40°

∴ BOE = 30°

• હવે , AOD + BOD = 180°( ∴ રૈખિક જોડ )

∴ AOD + 40° = 180°

∴ AOD = 180° - 40°

∴ AOD = 140°

• વિપરિત COE = AOC + AOD + BOD + BOE

વિપરિત COE = 40° + 140° + 40° + 30°

વિપરિત COE = 250°

પ્રશ્ર - 2) આક્રુતિમાં રેખા XY અને રેખા MN , O માં છેદે છે. જો POY = 90° અને a : b = 2 : 3 , તો c શોધો.

જવાબ : • અહીં , POY = 90°

અને a : b = 2 : 3 છે.

• ધારો કે , a = 2x , b = 3x

• હવે , POX + POY = 180° ( ∴ રૈખિક જોડ )

∴ a + b + POY = 180°

∴ 2x + 3x + 90° = 180°

∴ 5x = 180° - 90°

∴ 5x = 90°

∴ x = 90°/5

∴ x = 18°

અહીં , a = 2x = 2 × 18 = 36°

અહીં , b = 3x = 3 × 18 = 54°

• હવે , XOM + XON = 180° ( ∴ રૈખિક જોડ )

∴ b + c = 180°

∴ 54° + c = 180°

∴ c = 180° - 54°

∴ c = 126°

પ્રશ્ર - 3)આક્રુતિમાં , PQR = PRQ , તો સાબિત કરો કે PQS = PRT.

જવાબ - • અહીં , PQR = PRQ__________ (1)

PQR + PQS = 180° (∴ રૈખિક જોડ )

∴ PQR = 180° - PQS __________ (2)

• હવે , PRQ + PRT = 180° ( ∴ રૈખિક જોડ)

∴ PRQ = 180° - PRT __________ (3)

• સમીકરણ (2) અને (3) ની કિંમત સમીકરણ (1) માં મૂકતાં ,

∴ 180° + PQS = 180° + PRT

∴ PQS = PRT

પ્રશ્ર - 4 ) આક્રુતિમાં જો x + y = w + z હોય , તો સાબિત કરો કે AOB રેખા છે.

જવાબ - • અહીં , x + y = w + z ________ (1)

• અહીં , બિંદુ O આગળ બનતા તમામ ખૂણાઓનો સરવાળો 360° થાય છે.

∴ x + y + w + z = 360°

∴ x + y + x + y = 360° (∴ સમી. (1) પરથી )

∴ 2x + 2y = 360°

∴ 2 ( x + y ) = 360°

∴ x + y = 360°/2

∴ x + y = 180°

• અહીં , પૂર્વધારણા 6.2 મુજબ , બે આસન્નકોણોનો સરવાળો કરતાં 180° આવે , તો તેની સામાન્ય ન હોય તેવી બાજુઓ રેખા બનાવે છે.

∴ AOB રેખા છે.

પ્રશ્ર - 5 ) આક્રુતિમાં POQ રખા છે. કિરણ OR રેખા PQ ને લંબ છે. કિરણ OP અને OR વચ્ચે અન્ય કિરણ PS આવેલ છે. સાબિત કરો કે , ROS = 1/2 ( QOS - POS )

જવાબ - • અહીં , કિરણ OR રેખા PQ ને લંબ છે.

∴ POR = 90°

∴ ROQ = 90°

હવે , QOS = ROS + ROQ

∴ QOS = ROS + 90°

∴ QOS - ROS = 90° __________ (1)

હવે , POR = POS + ROS

∴ 90° = POS + ROS

∴ POS + ROS = 90° __________ (2)

સમીકરણ (1) અને (2) ને સરખાવતાં ,

∴ QOS - ROS = POS + ROS

∴ QOS - POS = ROS + ROS

∴ QOS - POS = 2ROS

∴ 1/2 ( QOS - POS ) = ROS

∴ ROS = 1/2 ( QOS - POS )

પ્રશ્ર - 6 ) XYZ = 64° આપેલ છે અને XY ને બિંદુ P સુધી લંબાવેલ છે. આપેલ સૂચના પરથી આક્રુતિ દોરો. જો કિરણ YQ , ZYP નો દ્વિભાજક હોય , તો XYQ અને વિપરીત QYP નું માપ શોધો.

જવાબ -

• અહીં , XYZ = 64°

PYZ + XYZ = 180° ( ∴ રૈખિક જોડ )

∴ PYZ + 64° = 180°

∴ PYZ = 180° - 64°

∴ PYZ = 116°

• હવે , કિરણ YQ , ZYP નો દ્વિભાજક છે.

∴ PYQ = QYZ = 1/2 ZYP

∴ PYQ = QYZ = 1/2 116°

∴ PYQ = QYZ = 58°

• હવે , XYQ = QYZ + XYZ

∴ XYQ = 58° + 64°

∴ XYQ = 122°

• અહીં , વિપરિત QYP = 360° - QYP

∴ વિપરિત QYP = 360° - 58°

∴ વિપરિત QYP = 302°
